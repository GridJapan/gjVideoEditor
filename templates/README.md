# テンプレートで動画を作る

台本JSONを1枚書いて1コマンド叩けば、動画が1本できます。**Pythonは書きません。**

```bash
python3 tools/make_video.py 台本.json --voice --render
```

---

## 最初の1回だけ：準備

### 1. 必要なもの

| もの | 確認 | 入れ方 |
|---|---|---|
| Python 3 | `python3 --version` | Win: Microsoft Store / Mac: 最初から入っている |
| Pillow | `python3 -c "import PIL"` | `pip install Pillow` |
| ffmpeg | `ffmpeg -version` | Win: `winget install Gyan.FFmpeg` / Mac: `brew install ffmpeg` |
| edge-tts | `python3 -m edge_tts --help` | `pip install edge-tts` |

**edge-tts は無料・APIキー不要**です。ナレーションはこれで作ります。

### 2. 素材キットを置く

テンプレートは**共通素材**（ロゴ・バナー・背景・効果音・BGM）を使います。
`assets/kit/` と `assets/bgm/` は clone 直後には**存在しません**（素材はGitに入れていないため）。

```
assets/kit/    ← ロゴ・バナー・背景・効果音（全テンプレ共通）・図解画像
assets/bgm/    ← BGM
```


自分で用意する場合は、まずディレクトリを作ってから素材を置きます。
**出所とライセンスが分かっているものだけ**を入れてください。

```bash
mkdir -p assets/kit assets/bgm
```

素材が足りないと `make_video.py` が**足りないファイル名を挙げて止まります**。書き出してから気づくと手戻りが大きいためです。

### まず動かしてみる（動作確認）

配置できたら、付属の実例がそのまま動きます。

```bash
python3 tools/make_video.py templates/example-sns-explain.json --voice --render
```

`projects/example-explain/out/example-explain.mp4`（約40秒）ができれば、環境は正常です。
**自分の台本を書く前に、まずこれを通してください。** どこで詰まるかが先に分かります。

## 動画を1本作る

### 手順

```bash
# 1. 実例をコピーして中身を書き換える
cp templates/example-sns-explain.json projects/my-script.json

# 2. 音声を作って組み立てて書き出す（まとめて）
python3 tools/make_video.py projects/my-script.json --voice --render
```

できあがりは `projects/<name>/out/<name>.mp4` です。

**やり直すとき**は `--voice` を外すと音声を作り直しません（時間短縮）。文章を変えたときだけ付けます。

---

## 型は2つ

### `sns-explain` — 図解＋ナレーション＋字幕

数字や調査結果を扱う説明系。

```json
{
  "template": "sns-explain",
  "name": "my-explain-01",
  "chip": "#中小企業とAI",
  "source": "出典: ○○「△△調査」(2026年3月公表)",
  "bgm": "chill-223am.mp3",
  "hook":  {"text": "掴みの一言\n2行まで", "dur": 3.0},
  "beats": [
    {"id": "n1", "narration": "読み上げる文章", "caption": "画面に出す字幕",
     "image": "c1", "layout": "boxed"}
  ],
  "outro": {"text": "締めの言葉", "dur": 4.6}
}
```

| 項目 | 意味 |
|---|---|
| `narration` | 読み上げる文章。`tts` を別に書くと読みだけ変えられる（例: `"AI"` → `"エーアイ"`） |
| `caption` | 画面に出す字幕。**`**〜**` で囲むと金色**になる（UIエディタなら文字を選択して「★ 強調」ボタンでも付けられる） |
| `image` | 使う画像のファイル名（拡張子なし）。`c1` なら `c1.png` |
| `layout` | 下表から選ぶ。**省略すると文字数で自動**（12字以下＝画像に重ねる） |
| `voice` | 声を変えたいとき。既定は `narrator-m` |
| `caption_ja` | 日本語の副字幕（小さく下段に出る）。海外向けの型（`sns-global`）専用 |
| `caption_style` | その字幕だけ見た目を変える。例: `{"highlightColor":[86,24,28,238]}`。**ここに書けば作り直しても消えない**（`patch.py` で当てた分は `--force` の再ビルドで失われる） |

**字幕を動かす**（`caption_style` の中に書く）

| 書き方 | どう見えるか |
|---|---|
| `{"anim":"countup"}` | **金額が0から実値へカウントアップ**。順位の`#2`や`10 min`は動かない（金額だけ） |
| `{"anim":"typewriter"}` | 1文字ずつ出る。フックの引きが強くなる |
| `{"anim":"slide","slideFrom":"left"}` | 画面外から滑り込む |
| `{"bar":{"ratio":0.07,"color":[120,210,150,255]}}` | 字幕の下に**比較バー**。`countup`と併せると数字と一緒に伸びる |

比較動画では **`countup` + `bar` の組み合わせ**が効きます。
`$139`は満タン、`$10`は7%の棒——13倍の差が数字を読まなくても伝わります。

**レイアウトの型**（左上固定にしないため、内容で選ぶ）

| 型 | 字幕の置き方 | 使いどころ |
|---|---|---|
| `over_img` | 画像に重ねる・中央 | セリフ、断言 |
| `boxed` | 枠を広げて縦横中央 | 説明 |
| `side_l` / `side_r` | 左／右に寄せる | 数字、列挙（左右で振るとリズムが出る） |
| `over` | 上に置く | 図解をじっくり見せたいとき |

### `chat` — LINE風チャット

会話の往復そのものが中身のネタ。

```json
{
  "template": "chat",
  "name": "my-chat-01",
  "chip": "#社内のAIルール",
  "source": "出典: ○○",
  "chat": {
    "title": "社内チャット",
    "speakers": {"A": {"name": "営業部 田中", "side": "left"},
                 "B": {"name": "総務部 佐藤", "side": "right"}},
    "lines": [{"who": "A", "text": "1つ目の発言"},
              {"who": "B", "text": "2つ目の発言"}]
  },
  "beats": [
    {"id": "v1", "narration": "導入のナレーション", "card": "**掴み**の一言"},
    {"id": "v2", "narration": "1つ目の発言", "voice": "narrator-m", "screen": 1},
    {"id": "v3", "narration": "2つ目の発言", "voice": "narrator-f", "screen": 2},
    {"id": "v4", "narration": "締めのナレーション", "screen": "fade", "card": "**26.0%**"}
  ]
}
```

- `chat.lines` に書いた会話から、**チャット画面が自動で作られます**（発言ごとに1枚）
- `screen` に番号を書くと、その時点までの会話が映ります
- `screen: "fade"` は**チャットを薄くした締め用の画面**。数字カードを重ねても読めます
- 話者ごとに `voice` を変えると会話らしくなります（`narrator-m` と `narrator-f`）
- **字幕は出ません**。吹き出しの中の文字が字幕そのものなので二重になるためです

## 詰まりやすいところ

**「音声 n1.mp3 がありません」**
→ `--voice` を付け忘れています。文章を変えたときも付け直してください。

**「素材が見つかりません」**
→ 素材キットが未配置です。上の「素材キットを置く」を見てください。

**書き出しが遅い**
→ 1080×1920の縦動画40秒で、Mac実測 30秒前後です。数分かかるようなら、
　 画像に付けた `motion`（ズーム）が多すぎないか見てください。ズームは処理が重く、
　 1本に1〜2枚だけ付けるのが作法です。

**画像を新しく作りたい**
→ 画像生成には `codex` CLI が要ります。持っていない場合は**素材キットの画像を使い回してください**。同じ図解でも字幕とレイアウトが変われば別の動画に見えます。

**字幕の最後の1文字だけ次の行に落ちる**
→ `caption` に `\n` を入れて自分で改行位置を決めてください。
　 `--lint` が**実際の描画幅で**「枠に収まらず2行に折り返されます」と教えてくれます
　 （文字数では欧文と和文で幅が2倍違うため当てになりません）。

**字幕が □□□ になる**
→ そのフォントがその文字を持っていません。`--check`（`tools/patch.py`）が書き出す前に検出します。
　 中国語（簡体字）を出すなら `style.font` を `Hiragino Sans GB` にしてください。

**効果音が思ったところで鳴らない**
→ 前の音が鳴り終わるまでは次を置かない作りです（重ねると音が濁り、検査にも弾かれるため）。詰まって聞こえるときはナレーションの間隔を空けてください。

## 数字を出すときの約束

この系統は**出典を画面に常時出します**。`source` を必ず埋めてください。

- 数字は**必ず一次情報（公式サイト・調査元のPDF）で確認**してから書く
- 「〜と言われている」で数字を出さない
- 調査対象（従業員規模・回答数）が自社の話と違うときは、それも書く

AIに調べさせた数字をそのまま使わないでください。**実際に間違っていたことがあります。**
