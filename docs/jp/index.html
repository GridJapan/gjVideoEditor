仕組み できること ビューア 導入 日本語 / EN GitHub

開発中 · v0.10.0

AIで作った動画を、そのままUIで編集できる。

「この動画を作って」と頼んで出てきたものを、タイムラインで直接いじれます。 直したあとにまた言葉で指示しても、UIでの手直しは消えません。

Python標準ライブラリ ＋ Pillow ＋ ffmpeg だけ。クラウドもAPIキーも不要です。

編集画面。clone した直後にこのサンプルが動きます

01 / 仕組み

AIとUIが、同じ1つのファイルを書き換える

AIに動画を作らせると、たいてい出てくるのはコード（React や HTML）です。 中身を1か所直したいだけでも、コードを読むかAIに頼み直すことになります。

このツールでは、AIも人も project.json という1枚のファイルだけを書き換えます。 だからAIが作ったものをそのままタイムラインで編集でき、そのあとまた言葉で指示しても、 手で直した内容は残ります。

AIが書く（8割）

差分パッチとして当たります。重なり・素材の欠落・尺の超過は保存する前に弾かれるので、壊れたものができません。

人が直す（2割）

ブラウザのタイムラインで直接動かします。他所からの更新とぶつかれば検知して止まります。

さらに、人が直した内容をAIが読み返せます。同じ直しが繰り返されているなら、それはAIの既定値が間違っているということです。

02 / できること

ふつうの編集はひととおり

タイムライン編集映像・字幕・画像・音声のマルチトラック。ドラッグ&ドロップ、分割、undo/redo、吸着、ズーム
非破壊編集長い元動画を1本置いたまま、参照位置だけをずらして使います。切り出しファイルを作らないので、端をいつでも伸ばせます
字幕枠のドラッグ・リサイズ・フォント・360°回転・縦書き・部分強調・画面端への吸着
ワイプ（PiP）プレビュー上でドラッグして移動・拡大縮小。角丸を1.0にすると正円になります
書き出しMP4 / WebM / GIF / MP3。画質と解像度を選べます
ナレーション無料でAPIキー不要の音声合成に対応。複数の声を使い分けられます
量産台本を1枚書いて1コマンドで動画が1本。Pythonは書きません

このツールで作った動画

下の28秒の動画も、このツールで組み立てて書き出したものです。

図解はAIで生成、ナレーションは無料の音声合成。組み立て・BGM・効果音・書き出しはこのツール

03 / ビューア

作った動画は、その場で見返せる

ロゴをクリックすると GJ VIDEO VIEWER が開きます。 書き出した動画が新しい順に並ぶので、ファイルを探しに行かずに再生して確認できます。

左が書き出し済みの一覧、右がプレイヤー。ループ再生にも対応しています

一覧プロジェクトを横断して、書き出した動画を新しい順に表示します。任意のフォルダも開けます
再生サムネイルは自動で作られ、2回目以降は即座に開きます。🔁 でループ再生もできます
戻るエディタに重ねて開くだけなので、閉じれば再生位置も選択もそのままです
04 / おすすめの使い方

左に相棒、右に道具

Claude デスクトップアプリから Claude Code を起動し、 左でチャット・右のプレビューペインでこのエディタを開く構成が一番はかどります。

1つの画面の中で「頼む → 触る → 見る」が完結します

左「BGMもう少し小さく」「ロゴを右上に」と日本語で指示すると、差分が当たります
右そのまま編集UIとして操作できます。書き出した動画の確認もここでできます

リポジトリには作法を書いた CLAUDE.md が入っているので、 Claude Code はこのツールの流儀を最初から知った状態で作業します。 もちろん、Claude を使わずに単体でも普通に動きます。

05 / 導入

AIに頼むのが、いちばん簡単

下の依頼文をコピーして、普段使っているAIエージェント（Claude Code / Codex / Cursor など）に送ってください。 できるところはAIが進め、あなたの操作が必要なところだけ案内します。 git やターミナルが分からなくても大丈夫です。

この依頼文をコピーして、AIに送る 
video-editor をこのパソコンにセットアップして、起動するところまでお願いします。

リポジトリ: https://github.com/GridJapan/gjVideoEditor

手順:
1. 適当な作業フォルダに git clone する
2. 必要なものが入っているか確認する（python3 tools/_deps.py を実行すると一覧が出ます）
   足りないものがあれば入れ方も表示されるので、それに従って導入してください
   - Python 3 / ffmpeg が必要です（Pillow は初回起動時に自動で入ります）
3. python3 tools/make_sample.py を実行してサンプル素材を作る
4. python3 ui/server.py でサーバを起動し、http://localhost:8765/ をブラウザで開く

うまくいったら、サンプルの動画を書き出すところまで試して結果を教えてください。
  python3 renderer/render.py projects/sample-hello

インストールの許可など、私の操作が必要な場面があれば教えてください。

パスワードの入力やインストールの許可など、あなた自身がやる必要がある場面ではAIが止まって案内します。

自分でやる場合は3ステップ

# 1. 取得
git clone https://github.com/GridJapan/gjVideoEditor.git
cd video-editor

# 2. サンプルの素材を作る（初回だけ）
python3 tools/make_sample.py

# 3. 起動 — Mac は start.command、Windows は launch.bat をダブルクリック

ブラウザが開いて、サンプルが読み込まれた状態で始まります。

必要なもの

MacWindows
Python 3最初から入っていますMicrosoft Store から
ffmpegbrew install ffmpegwinget install Gyan.FFmpeg
Pillow初回起動時に自動で入ります

足りないものがあれば、起動時に入れ方つきで教えてくれます。 いま何が入っているかは python3 tools/_deps.py で確認できます。
