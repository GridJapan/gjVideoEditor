# 編集UI（ui/editor.html）の作法

素のHTML/JS 1枚。**フレームワークを入れない**（依存ゼロが配布条件）。

## プレビューと書き出しを食い違わせない（最頻の事故）

- **字幕の描画は `renderer/render.py` の `render_caption_image()` が唯一の実装**。
  プレビューは `/api/caption-preview`（POST）でこれを呼びPNGを重ねる（ドラッグ中だけCSS簡易表示）。
  **CSSで再現し直さないこと** — 分岐させた瞬間に書き出しとズレる
- 映像に `x/y` などを足したら、プレビュー側にも必ず実装する
- **crop の意味は「切る→目標幅(W*scale)へフィット→配置」**（切ると残りが拡大される）。
  プレビューは外枠 `.vwrap`(overflow:hidden) ＋ 中身 `video`(1/kw倍に広げて負オフセット) の2層で同じ絵を作る。
  **clip-pathで隠すだけの実装に戻さないこと**（拡大も再配置もされず全く違う絵になる）

## DOM を index で引かない

`#lanes` の子は `proj.tracks` と **1:1ではない**。映像トラックの直後に波形レーン(`.audio-wave`)が
挿入されるため、`children[ti]` は下のトラックほどズレる。

- レーン/クリップは `laneBodyFor(ti)` / `clipElFor(ti,ci)`（`data-ti` で引く）を使う
- 波形も `.lane.audio-wave[data-ti="N"]` でトラックを絞る（文書内の最初の1件を取ると別トラックが動く）

## インスペクタ

- **`build()` を入力ハンドラから呼ばない。** `build()` は末尾で `renderInspector()` を呼び、
  `renderInspector` は `box.innerHTML=''` するため、**1文字打つごとに入力欄ごと消える**
  （フェード秒がこれで入力不能だった）。`input` は軽量更新、`change` で `pushHistory()`
- **項目ごとに区切り線**（`.frow2` の border-bottom）。行を足すときもこの構造に乗せる
- **色は「現在色の●」1個だけ**。クリックで `openSwatchPop()`。**全色スウォッチを常時並べない**
- **スライダーは固定幅150px**。`flex:1` / `width:100%` にしない（ウルトラワイドで果てしなく伸びる）
- **縦の縮尺 `--vscale`**: レーン/クリップ/波形の高さは `calc(◯px*var(--vscale,1))`。
  **高さ固定pxを直書きしない**（縮尺から外れて崩れる）

## ツールバー

- **ボタンを直に並べない。ドロップダウンにまとめる**（`＋クリップ ▾` / `＋トラック ▾` / `✨エフェクト ▾`）
- **新しいメニューは `toggleMenu(btnId,menuId)` を使う**。ツールバーは画面下寄りにあり、
  下に開くと画面外へ切れる。開く向きの判定はこの関数に集約してある
- 閉じるのは `closeMenus()`。documentのクリックで自動的に呼ばれる
- **アイコンだけのボタンは `.icobtn`**（36x36）。`↶↷` のような記号文字は使わない
  ——フォント依存でWindowsでは豆腐になる。**SVGで描く**（16x16・stroke・currentColor）

## クリップ配置は1か所で判定する

重なり禁止は **ドラッグ・ペースト・複製・外部ファイルドロップの全経路**が守ること。
`overlapsIn(clips, cc)` で判定し、`findFreeStart(clips, start, len)` で空きへ送る。

- 経路ごとに実装すると必ず抜ける（⌘D複製が必ず元と重なり、以後ドラッグしても常に赤で戻される
  ＝削除以外できない詰み状態になっていた）
- 複製は**元クリップの直後**に置く。プレイヘッド基準だとほぼ必ず元の内側＝重なる

## 素材のキャッシュ

同名で素材を上書きすると**ブラウザキャッシュで古い絵/音が出る**（`Cache-Control: no-cache` では防げなかった）。

- 画像・音声のURLは必ず `assetUrl()` を通す（`load()` のたびに更新される `ASSET_V` が付く）
- `/asset?name=` の直書きをしない

## ビューア

**ロゴ「🎞 video-viewer」またはヘッダのロゴをクリック**で開閉する。

- **オーバーレイ方式**（`#viewer` を重ねるだけ）。エディタのDOMに触らないので、閉じれば再生位置も選択も残る。
  **別ページにしないこと**（戻ると編集状態が消える）
- 閉じるとき `video` の src を外す。**外さないと裏で読み続ける**
- 一覧はメタデータのみ。`preload` させない

## その他

- **終了した `<video>` に `play()` すると先頭に巻き戻る**（HTML5仕様）。クリップ終端では `play()` を呼ばない
- 波形はソース画像を**クリップ幅に引き伸ばして描画**する → 素材が無い区間にも波形が見える。尺の判断に使わない
- **映像はクリップ単位で `<video>` を持つ**（`videoEls` のキーは `"ti-ci"`）。
  srcキーに戻すと要素を共有して1本しか出せなくなるので戻さないこと
