## 狙い

**視聴維持率**（回るほど再生数が伸びる＝YouTubeアルゴリズム対策）。**尺は20秒程度**。

> 本当にいいショートの策略は、**ループしてることに気づかせない**

## ★ループ点は「元々ひと続きだった所」に置く（最重要）

**繋ぎ目を消す唯一確実な方法は、元の録画で連続していた発話の途中で切って輪にすること。**
声の高さ・息継ぎ・部屋の響きが完全に一致するので、繋ぎ目が原理的に存在しない。

```
元の発話:  …ドライバーが片手運転スマホいじってたら／超面白いじゃないですか／4人全員スマホ触ってたらすごいですね
                                                    ↑ここで切る
動画:      [4人全員スマホ…] → 本編 → […超面白いじゃないですか] → ループ → [4人全員スマホ…]
```

**検証: ループ点をまたいだ音声を切り出してwhisperにかける。** ひと続きの文として書き起こされたら成功。
（実測: 「超面白いじゃないですかそれで4人全員スマホ触ってたらすごい」＝繋がっている）

⚠️ **やりがちな失敗**: 結論で終えて冒頭の導入（「〜ですよね」）へ戻す作り。
これは話題の振り出しに戻るだけで、聞けば一発で「また始まった」と分かる。
**画素差分が一致していてもループにはならない**（2026-07-21 実際にやった）。

## 構成（オチから始める）

「オチ → なぜそうなったか → 最後の一言が冒頭のフリになる → 冒頭へ」の円環にする。

例: 「なんで事故を起こしたんですか？」→「実はちょっと開発してまして」→ 背中にMac →
国道を爆走 → スマートグラス →「**…いつか事故るやつですよね**」→ 冒頭の問いへ。

**最後の一言が冒頭の問いのフリになっていること**が肝。ここが繋がらないと、ただの尻切れになる。

## 気づかせないための実装（普通の動画とわざと変える点）

1. **冒頭にタイトルカードを置かない** — 「始まった感」が出て一発でバレる（張り紙タイトルは使わない）
2. **最初と最後を同じ画にする** — ループ境界で絵が変わらない＝繋ぎ目が消える
3. **フェードイン/アウトを付けない** — フェードは「終わり」の合図
4. **全編表示の要素は本当に全編に置く**（注意書き・チップ・帯）。
   途中から出す要素があると、ループした瞬間に消えてバレる（実際に踏んだ）
5. **BGMは極小(gain 0.03)** — ループ点でBGMが鳴り直すのが最大のバレ要因
6. **効果音をループ境界に置かない**

### ループ境界の画にモーションを付けない

先頭と末尾に同じ画を置いても、**そこにKen Burnsを付けると末尾はズーム最大・冒頭はズーム開始**に
なるので拡大率が違って繋ぎ目が見える（2026-07-21 実測: 紙芝居の差分が 1.4 → 37.5 に悪化）。
モーションは**中間の画**に付ける。

## カットの選び方（限定詞を落とさない）

**「〜は」「ただ」「3人乗り以上で」のような限定詞を落とすと、前半と矛盾して聞こえる。**

2026-07-21の実害: 「みんな片手スマホ運転が日常」と言った直後に
「スマホ片手運転してる人はまだ見たことない」を置いてしまった。
原文は「**3人乗り以上で**スマホいじって片手運転してる人はまだ見たことない」で、
限定詞を落としたせいで同じ対象の話に聞こえた。

- カットを選んだら、**字幕だけを上から通しで読んで**、話が矛盾しないか確認する
- 反転する所には「ただ、」「でも」を残す（これを削ると論理が消える）
- **オチになる発言を使い切ったか**も確認する

## 素材の安全確認（ループに限らず必須）

**ワイプに使う区間は、必ず先に数フレーム抜いてレイアウトを見る。**

会議録画は区間によって「話者の顔だけ」と「画面共有が主・カメラは右端の小窓」が混在する。
後者をそのまま使うと投稿・検索履歴・社内資料が映る（2026-07-21 実際に踏んだ）。

カメラ枠は**上下に黒帯がある列**を探せば数値で特定できる（目視で座標を決めない）:

```python
top = a[:100].mean(axis=0)                              # a=グレースケール配列
bot = a[-100:].mean(axis=0)
cam = [x for x in range(W) if top[x] < 25 and bot[x] < 25]   # → その範囲を clip.crop に入れる
```

## プレビューでの確認

**シークバー右の 🔁 ボタン**でループ再生できる（`ve_loop` に保存）。
一番右端のクリップの終わり（＝`realDur()`）まで来たら先頭へ戻る。繋ぎ目を何周も見て確かめる用。

## 検証のしかた（目視でなく実測する）

```bash
# 2周つなげて繋ぎ目を見る
printf "file '%s'\nfile '%s'\n" "$PWD/out/x.mp4" "$PWD/out/x.mp4" > /tmp/cat.txt
ffmpeg -f concat -safe 0 -i /tmp/cat.txt -c copy /tmp/loop2.mp4
```

末尾フレームと先頭フレームを**領域ごとに差分**を取る。合格ラインの実測値:

| 領域 | 差分 |
|---|---|
| ロゴ | 0.6 |
| 紙芝居 | 1.4 |
| 帯 | 1.0 |
| 注意書き | 4.1 |
| ワイプ | 5.3 |

**字幕だけは違って良い**（会話が続くので自然。実測58.1）。
