# モーション・エフェクトの流儀

## 目次

- 大原則（動きは意味のある瞬間だけ）
- 静止画（紙芝居）のモーション
- 一撃系エフェクト（集中線・ポップ・揺れ）
- エフェクトの設計（2種類しかない）

## 大原則

動きは**意味を持つ瞬間にだけ**使う。動き自体に意味はなく、**動きが珍しいから目が行く**。
常時動かすと「珍しさ」が消えて、残るのは見にくさだけ——**実際に「酔う」と実害報告が出た**。

## 静止画（紙芝居）のモーション

- **既定は完全静止。** 間延びの解決は動きではなく、**カット割り・字幕の切り替え・効果音**でやる
- Ken Burns（`"motion":{"zoom":1.08}`）は **1本の動画で1〜2枚だけ**、意味のある画に付ける:
  - **寄り（zoom 1.05〜1.08）** = 核心・オチ・「ここを見ろ」の画
  - **引き（zoom 0.93〜0.95）** = 状況全体を見せる導入の画
- **全画像への適用・寄り引きの交互適用は禁止。** それは「型の機械適用」であって演出ではない
  （2026-07-17: 4本全部が交互ズームになっていて作り直した。この日の轍を二度と踏まない）
- zoom は 1.10 を超えない。ゆっくり僅かに、が上限

`zoom>1`=寄り／`zoom<1`=引き（1/zoomから等倍へ）。クリップ長をかけて中央基準でズームする。
プレビューは簡易表現（枠クロップでなく要素拡大）なので、正確な見えは書き出しで確認する。

## 一撃系エフェクト

### 集中線

```bash
python3 tools/gen_fx.py lines --out projects/<名>/fx_lines.png
```

決定的生成（生成AI不要・seed固定）。UIのツールバー「⚡集中線」でも再生位置に挿入できる
（`POST /api/gen-fx` がキャンバス寸で生成→fxトラックへ1.2秒）。

**衝撃・驚きの一撃の瞬間だけ 0.8〜1.5秒**、band より上の fx トラックに置き、
**効果音（text-impact等）と同時**に出す。常時表示・1本に3回以上は禁止（薄まる）。

### ポップ登場 `"anim":"pop"`（字幕）＝スタンプ

1.9倍から**0.16秒で叩きつけて**等倍に貼り付く（＋0.06秒フェードイン）。
**ドーン系効果音と同時のカード（フック・まとめ）に付ける**のが基本形。

音だけ鳴って画が動かないのは「ヘン」——逆に、音のない所にポップだけ置くのも不自然。

⚠️ **「小さく縮んで収まる」「ゆっくり0.3秒」は不成立**
（「ドーンなのに小さくなる意味がわからん」2026-07-17実害）。
ドーンは**大きい→速く叩きつけ**の一方向。

### 揺れ（shake）

未実装。実装しても**一撃 0.3秒まで**。持続的な揺れは絶対に作らない。
（持続ズームの微ジッタを「揺れ演出」と誤認されたのが発端。揺れは事故であって演出ではない）

## エフェクトの設計

**エフェクトは2種類しかない。新しい演出を足すときは、どちらかに必ず振り分ける。**

| | オーバーレイ型 | クリップ属性型 |
|---|---|---|
| 例 | 集中線・フラッシュ | 寄り/引き・角丸・スタンプ登場 |
| 実体 | **ただの画像クリップ**（尺と位置を持つ） | クリップのプロパティ（`motion`/`radius`/`anim`） |
| 適用先 | タイムライン（再生位置） | 選択中のクリップ |

- **専用トラックを毎回作らないこと。** `overlayTrackFor(st,en)` が既存の画像トラックから
  **その区間が空いているもの**を探して置く。全部埋まっている時だけ新規作成する
  （押すたびトラックが増えるのは編集ソフトとして異常）
- **単体のエフェクトをツールバーに直接置かないこと。** 「✨エフェクト ▾」のライブラリに入れる。
  カテゴリは**1段まで**
- **クリップ属性型は種別ガードを必ず入れる**（字幕にズームを付けようとしたら弾いて理由を出す）

調査結果（Premiere/CapCut/Resolve/FCPを調べて決定・2026-07-17）:
プロ系3本は「エフェクト＝クリップの属性」で統一し、独立トラックが要る時だけ
**調整レイヤーというクリップ**を置く。CapCutだけが「派手なオーバーレイ＝独立レイヤー /
色補正＝クリップ付属」と役割で分ける。**うちはCapCutの二分法**（実装が破綻しにくい）。

## 角丸

`"radius":0〜1`（画像・映像共通）。1.0で中央の正円（短辺基準）＝ワイプを丸にする用途。
画像はPIL前処理（既存の透過と乗算＝集中線等にも安全）、映像はscale後の実寸マスクをalphamerge。
プレビューはCSS border-radius / clip-path circle の近似。
