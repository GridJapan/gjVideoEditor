## 40秒級ショートの骨格

**骨格は型だが、中身の判断（どこを切るか・並べ替えるか）はAIの仕事。**

1. **フックカード**（約3秒・紺箱白字）
2. **本編ジャンプカット**（whisper単語タイムスタンプから選定）
3. **ブリッジカード**（約1.5秒・展開の切り替え）
4. **オチ**
5. **まとめカード**（約4.5秒・黄箱紺字）

目安: **画像 約6秒/枚**（8秒超は間延び）、**字幕 約2.5〜3秒/本**（1カットに2〜3本で刻む）、カード3枚。

**時系列の並べ替えは状況判断。** 結論ファーストが効くネタだけ核心を先頭へ。
時系列のままが自然ならそのまま。

効果音はカード出しと同時が基本。同一トラック内で重ねない（鉄則）。装飾音は第2トラックへ。

## 標準レイアウト（全動画共通）

```jsonc
ロゴ  : {"x":0.579, "y":0.027, "w":0.38}                        // 右上
ワイプ: {"x":0.72, "y":0.644, "scale":0.28, "radius":1}         // 正円・字幕エリアの右下
```

ワイプ右上・長方形は旧配置。**新規はこの配置から始める。**

## レイアウトは「型」で切り替える（ランダムにしない）

1本の中で同じ配置が続くと単調になる。ビルダーの `LAYOUTS` に4つの型を持たせ、
**カットの内容で選ぶ**（ランダム抽選ではない）:

| 型 | 画像 | 字幕 | 使いどころ |
|---|---|---|---|
| `over_img` | 縦いっぱい | **画像の上に重ねる**・中央 | セリフ・断言 |
| `boxed` | 縦いっぱい | **枠を大きくとり縦横中央** | 説明 |
| `side_l` / `side_r` | 縦いっぱい | 左／右に寄せる | 数字・列挙（左右で振る） |
| `over` | 下げる | 上に置く | 図解をじっくり見せる |

- **左上固定はしない**（「左上に固定されている意味がわからん」2026-07-21指摘）。
  字幕が小さく余白が余るなら、**枠を広げてテキストを縦横中央**に置く
- 全カットに `anim:"pop"` と緩いズーム（`motion.zoom` 1.04〜1.10）で動きを付ける
  ※ ズームの上限と使いどころは motion-and-effects.md を参照
- 指定が無ければ**文字数で自動**（12文字以下＝`center`）
- ⚠️ `center` で画像を小さくしないこと（余白が生まれる。2026-07-21実害）
- ⚠️ `full` の字幕は出典(y=0.735)と重ならない位置に置く

## 字幕は画像の直下に置く（数値で確かめる）

16:9の画像を全幅で置くと高さは **1080×768/1344 = 617px**。
字幕を離しすぎると**画像の下に空白が残る**（2026-07-21実害: 218〜352pxの空きが出た）。

型を足すときは必ず計算して確かめる:

```
画像の下端 = img_y*1920 + 617
字幕の位置 = cap_y*1920
→ 差が0付近になるようにする
```

## 字幕の位置は固定する

**ランダムに動かさない。** ビルダーの `CAP_Y` で一元管理し、動画ごとに変えない。
（演出のバリエーションはA/Bで測るもので、1本の中で散らすものではない）

## 画像は画面を埋める（余白は2割まで）

**生成プロンプトに「画面いっぱいに配置・中央に小さい図がぽつんとある構図は不可」と明記する。**
書かないとスカスカな図が返る（実測: 指定なし17.7% → 指定あり27〜42%）。
被写体を大きく描き、周辺に関連アイコン・矢印・グリッド線を散らして密度を作る。

## 結論・数字は色で立たせる（`**〜**`）

字幕テキストを `**〜**` で囲むと、その範囲だけ **emphasisColor（既定=金 #d6ad5c）** で描かれる
（`renderer/render.py` の `parse_emphasis()`。行内の部分強調に対応、折り返しをまたいでも追従する）。

全部同じ色だと「どこが結論か」が伝わらないので、**1カットにつき1箇所**を目安に囲む:

```python
"足りない情報の1位は\n「成功事例・活用事例」**83.3%**"   # 数字
"実は、**お金じゃない**"                              # 結論
```

⚠️ 閉じ忘れた `**` は文字としてそのまま出る（文章が消えるより気づけるほうが良いという判断）。
色を変えたいときは clip に `emphasisColor: [r,g,b]`。

## 1文字だけ次行に落とさない（孤立行）

自動折り返しに任せると「持っていない**人**」「向上**する**」のように1文字だけ次行に落ちる。
書き出し前にフレームを見て、落ちていたら**明示改行 `\n` で割り直す**（2026-07-21実害）。
